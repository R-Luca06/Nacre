# Shortcuts

All of them can be changed in Settings → Shortcuts or under `[keys]`.

|                       |                                                           |
| --------------------- | --------------------------------------------------------- |
| ⌘T / ⌘W / ⌥⌘W         | New tab / close pane / close tab                          |
| ⇧⌘T                   | Reopen closed tab                                         |
| ⇧⌘[ / ⇧⌘] · ⌘1…9      | Previous / next tab · go to tab                           |
| ⌘D / ⇧⌘D              | Split right / down                                        |
| ⌥⌘←↑→↓ / ⌃⌘←↑→↓       | Focus / grow pane                                         |
| ⇧⌘↩ · ⌃⇧⌘E            | Zoom pane · equalize                                      |
| ⌥⌘I                   | Broadcast input to the tab                                |
| ⌘N / ⇧⌘W              | New window / close window                                 |
| ⌘F · ⇧⌘K              | Find · clear                                              |
| ⌘↑ / ⌘↓               | Previous / next prompt                                    |
| ⇧⌘O                   | Copy last output                                          |
| ⇧⌘U · ⇧⌘X             | Pick from screen (hints) · copy mode                      |
| ⇧⌘P                   | Command palette                                           |
| ⇧⌘H · ⇧⌘J · ⇧⌘S · ⇧⌘R | History · directories · snippets · SSH hosts              |
| ⌘K · ⇧⌘E · ⌥⌘F · ⇧⌘A  | Command from text · explain error · suggest fix · AI chat |
| ⇧⌘C · ⌥⌘C · ⌃⌘C       | Claude sessions · Claude in split · Claude panel          |
| ⌃Space · →            | Completions · accept the gray suggestion                  |
| ⌥⌘E                   | Edit the command on several lines (⌘↩ runs, ⇧⌘↩ inserts)  |
| ⇧⌘\\                  | All tabs                                                  |
| ⇧⌘V                   | Clipboard history                                         |
| ⌘= / ⌘- / ⌘0          | Text size                                                 |
| ⌘,                    | Settings                                                  |

In copy mode: `h j k l w b 0 ^ $ g G`, `⌃u ⌃d ⌃b ⌃f`, `v` / `V` select, `y` copy, `q` quit.
