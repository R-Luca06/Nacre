# Configuration

`~/.config/nacre/config.toml` is created on first launch with every default commented out. Uncomment a line to change it; saving applies it at once. Settings (⌘,) edit the same file and keep your comments. An invalid value falls back to its default and shows a one-line error.

## Status bar segments

`cwd` `git` `time` `process` `cpu` `mem` `battery` `net` `tools` `kube` `docker` `aws` `venv` `claude` (= state, model, context, cost) `claude.state` `claude.model` `claude.context` `claude.cost` `claude.limits` (= `claude.limits.5h`, `claude.limits.7d`) `claude.duration` `custom:<name>` `plugin.<id>`

```toml
[[statusbar.custom]]
name = "load"
command = "sysctl -n vm.loadavg"
interval = 10           # seconds
warn = "^\\{ [2-9]"     # regex on the output
click = "top"           # typed in the pane on click
```

## Sync

Everything lives in `~/.config/nacre` (`config.toml`, `themes/`, `workspaces/`, `plugins/`), so it syncs like any dotfiles: symlink the folder or single files from your dotfiles repo (GNU stow works), or clone a gist into it (`git clone <gist-url> ~/.config/nacre`). Edits to the real files apply live. Settings → General also exports and imports `config.toml`.
